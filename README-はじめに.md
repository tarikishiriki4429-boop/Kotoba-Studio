# Kotoba Studio v4.6.0 — GitHub Pages / iPad用

## インストール・更新
1. 先に「書き出し → プロジェクト」で現在の作品をJSONバックアップしてください。録音音声が正しく含まれることも確認してください。
2. ZIPを解凍し、`index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` をGitHubリポジトリのルートにアップロードしてCommitします。READMEは参考用で配信には不要です。
3. GitHub Pagesが更新された後にSafariで再読み込みします。保存した作品を守るため「履歴とWebサイトデータを消去」はしないでください。

## 今回の改良
### 録音ボーカル（ボイス）
- **ボイスのパートに録音・音声取り込みを行うと**、元の歌声（音声ファイル）が再生音になります。解析音符は歌声の高さ・長さ・強弱を表示する参照情報です。再生やWAV書き出しで、解析音符を別の楽器音に置き換えません。
- 音符の高さ・長さ・強弱はピアノロールや譜面・音程グラフで確認できます。録音ボーカルの参考音符は個別ドラッグ編集しない設計です。
- 詳細編集に表示される「録音ボーカル — 元の声を再生」の波形付きクリップを横にドラッグすると、録音そのものと参考音符の位置が**同じ拍数だけ**移動します。開始拍の数値入力、±0.1拍ボタンでも移動可能。元の音声データ自体は書き換えません。
- 音符を楽器パートに手作業で配置すれば、歌の参考音程を見ながら伴奏を作れます。録音された声は別のパートに変換されません。
- **音声を保存するのはプロジェクトJSON／端末内の録音データです。MIDI書き出しには声の録音は含まれません。** WAV書き出しには再生される録音音声が入ります。

### エレキギター
- 「エレキギター」を独立したパートとして追加。新規プロジェクトには1トラック含まれ、旧プロジェクトでも「＋ トラック追加」から追加できます。
- 3種類の音色：**クリーン**（弦の響き）、**クランチ**（ロック）、**リード**（高ゲイン／伸び）。歪み量を調整できます。
- 鋼弦の振動の数理モデル＋ピックのアタック＋アンプの歪み＋キャビネット風フィルタを使用。生成した音符を再生・WAV出力・ライブミックスで使えます。
- サンプル音源や外部音源を取り込んでいないため通信不要です。**実物のエレキギター録音と同じ音質を保証するものではありません。** 音色・歪みを変更した場合、ライブミックスは再生し直すと音色の変更が反映されます。音量・パン・EQは再生中に変更できます。

## 確認・制限
- Chromiumブラウザ上の自動検証で、WAVボーカル4音の解析・波形の表示・クリップドラッグ・拍数数値移動・参考譜面との同期を確認。エレキギターのクリーン・クランチ・リードの音声生成とミックス試聴を確認。
- **iPad Safari実機では未検証**です。機種やSafariのマイク権限・デコード対応形式によっては正常動作しない場合があります。
- 同じURLでも異なる端末・ブラウザ間で録音や作品は自動共有されません。作品はこまめにJSONを書き出して保管してください。
- 先行バージョンで既に作ったボイスの演奏位置が録音とずれている場合は、移動前のバックアップを保持し、クリップ位置を確認してください。
