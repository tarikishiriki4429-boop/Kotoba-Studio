# Kotoba Studio v4.7.0 — ボーカル波形カット編集（iPad / GitHub Pages）

## 更新方法
1. **必ず更新前に「書き出し → プロジェクト（JSON）」で、録音音声を含むバックアップを作ってください。** ZIPを展開しても原稿・楽曲データはコピーされません。
2. ZIP内の `index.html`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png` の5ファイルを、現在のGitHub Pagesリポジトリのルートで同名ファイルと置き換え、Commitします。
3. Pagesへの反映後、Safariで再読み込みします。新しい編集画面が表示されない場合は、ページを閉じて開き直してみてください。録音を守るため **Safariの「履歴とWebサイトデータ」を消去しないでください。**

## 使い方：録音ボーカルをカット
「音符・録音」→「ブロックを編集（十字キー）」→ **ボイス** のパートを選択 → 「🎙 録音ボーカル」内の波形を操作します。録音ボイスがなければ先に録音か音声取り込みを行ってください。

- **前後のトリミング：** 紫色クリップの**左右端の白い取っ手**を指で左右にドラッグします。隠れた元音声は消えず、後で端を戻すこともできます。
- **途中で分割：** 時間軸の空白部分をタップして黄色い目印を置き、「✂ この位置で分割」を押します。拍数を直接入力しても構いません。
- **途中の一部だけカット：** 時間軸の空白を横になぞると開始・終了拍が入ります。「✂ 指定区間をカット」を押すと、指定範囲の音声がなくなります。**残りの声は自動では左詰めされません**。必要ならクリップをドラッグして詰めてください。
- **個別移動：** 分割した各クリップを直接ドラッグ。選択して開始拍を数値入力、または「← 0.1拍」「0.1拍 →」でも微調整できます。
- **クリップ全体削除：** 選択して「選択クリップを削除」。操作ミスは元に戻す（Undo）か「元の録音から復元」で回復できます。後者は編集した分割・移動状態をリセットします。
- **フェード：** クリップをタップしてフェードイン・アウト秒数を指定し「選択クリップへ適用」。切れ目のクリック音を抑えます。
- **試聴：** 「▶ 元の歌声」から、元の声質のままクリップの編集結果を試聴できます。楽器を含めた再生やミックス、WAV書き出しにも同じカット位置が反映されます。

音程ブロック・譜面・音程グラフは伴奏を作るための**参考表示**であり、ボーカルを電子音に変換しません。分割・移動・削除の操作に合わせて、参考音程の表示位置・長さも更新されます。

## データの扱い・注意
- 元の録音音声は **非破壊** で保存します。クリップは「元音声のどこを、曲のどこから鳴らすか」の編集情報です。同じ端末・同じサイトのローカル自動保存に編集情報と録音を保存します。別端末には自動同期されません。
- v4.6.0以前のプロジェクトJSONを読み込むことも想定しています。従来の録音は最初の操作時に1つの波形クリップとして扱われます。
- 分割・カット後のボイストラックで **途中録り直し** を行うと既存の編集が混ざるおそれがあるため、保護のため拒否します。別ボイストラックを作って録音してください。音声の丸ごと差し替えは既存音声を上書きするため、必ずバックアップしてください。
- MIDIには録音の声そのものは入りません。WAVとプロジェクトJSONを使ってください。
- Chromium上で分割、指定区間カット、個別移動、クリップ削除、フェード操作と表示の連動を確認しました。音声ミックスの切り抜き部分が無音・残す部分が元の音声であることも検証済みです。ただし **iPad Safari実機での最終確認は未実施**です。録音・ブラウザの権限・機種依存の動作は端末で確認してください。
