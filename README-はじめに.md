# Kotoba Studio v4.2.0 — 楽曲制作アプリ

既存の **Kotoba Music v3.8.0** を基に、構成・歌詞・コード・メロディ保管庫・MIDI入出力を追加した統合版です。外部の音声認識API・アカウント・課金・Netlifyは使用しません。Web Audioとブラウザ内のデータ保存機能を利用します。

## iPadで起動する（GitHub Pages：Netlify不要）

1. GitHubで新しいリポジトリを作成します。個人用ならリポジトリ名は `kotoba-studio` 等で構いません。GitHub Pagesを無料プランで利用する場合、公開リポジトリが必要になる場合があります。**コードは公開されますが、通常の楽曲や録音はGitHubへ送信されません。**
2. ZIPを解凍し、`index.html`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png` の5ファイルを、リポジトリ直下にアップロードしてCommitします。ZIPそのものをアップロードするだけでは動きません。
3. GitHubの **Settings → Pages → Build and deployment → Deploy from a branch** で `main` / `/(root)` を指定して保存します。
4. 公開された `https://＜GitHubユーザー名＞.github.io/＜リポジトリ名＞/` に **iPadのSafari** からアクセスします。アプリ内のマイク録音はHTTPS環境を前提にしています。
5. Safariの共有メニューから **ホーム画面に追加** を選ぶと、アプリアイコンで起動できます。一度必要なページを開くと、アプリ本体はオフラインでも利用できるようキャッシュを準備します。

**注意：** ネット接続がない状態で初回起動はできません。iPadのファイルアプリでHTMLを直接開いた場合、録音・ストレージ等が制限される場合があります。最初の動作確認は必ずSafari＋HTTPSで行ってください。

## v4.2.0 で追加した細かな編集とミックス

**ホーム → 作曲・編曲** を開くと、複数トラックの譜面・基準音・リードボーカル参照の下にピアノロールと「精密編集」があります。

- 音符を1つまたは複数選択 → **精密編集** の「開始位置」「長さ」「半音」「強さ（%）」「整列（音価）」を数値指定 →「選択音に適用」。時間は **0.001拍** まで指定できます。
- **コピー／切り取り／指定位置に貼付／分割／同音の連結／1刻み移動／長さの微調整** を利用できます。コピーした音符は別トラックにも貼付できます。Undo/Redoで復元できます。
- 声を録音したパートでは精密編集の下の「元の録音クリップを細かく編集」を展開。クリップ位置（拍）、先頭・末尾の除去秒数を指定できます。録音の元データを破壊せずに再生の対象範囲だけを変えます。**波形を手で切り貼りするマルチクリップ編集ではありません。**
- **ホーム → ミックス** ではトラックごとに **音量 0〜400%、パン 左右、3帯域EQ ±18dB、コンプレッサーの閾値と比率、リバーブ、音量オートメーション** をスライダーまたは数値入力で編集できます。オートメーションは「＋ポイント追加」を押して拍位置と音量倍率を変えます。
- これらのミックス効果は **同じステレオ音声計算エンジンで再生とWAV書き出しに反映** されます。MIDIは音符・コード用で、原音声と全ての音響効果を保証するものではありません。
- 録音・プロジェクト保存・読み込みには端末内のIndexedDBを利用します。旧版と**同じサイトのURL**で開けば従来の保存領域を引き継ぐ設計ですが、更新前に必ずJSONバックアップをファイルアプリへ書き出してください。

**今回まだ未実装**：任意の位置の波形カット・クロスフェード、複数オーディオクリップの自由な重ね合わせ、周波数帯を自由に増やせるパラメトリックEQ、実録音音声の高度なピッチ修正、外部VSTプラグイン、音の良し悪しを自動判定する機能。リバーブは軽量な簡易方式です。

## 基本操作

- **演奏・音符・録音**：楽器トラックを追加。録音ボタンから鼻歌を録り、音符に変換。ダブルタップで音符追加、ドラッグで位置や長さの調整。音符を1つ選んで「音符に対応する歌詞」を入力できます。録音された原音もプロジェクト内に保持します。
- **構成・コード・歌詞**：イントロ・Aメロ・サビなどのセクションを管理。選択した区分に歌詞を入力し、メジャー・マイナー等のコードを指定できます。コードはガイドピアノとして曲の再生とWAVに反映されます。録音音声がある場合、セクションの並べ替え等は安全のため制限されます。
- **メロディ保管庫**：編集したトラックを「保管」して別曲でも音符や音声を取り出せます。音声ファイルを直接保管することもできます。メロディ保管庫はプロジェクトとは別にブラウザのIndexedDBに保存されます。
- **保存・出力**：「音量・保存・音の確認」のメニューから、録音込みプロジェクト（JSON）の書き出し・読み込み、楽曲のWAV書き出しができます。構成画面からMIDIを読み込み・書き出しできます。MIDIには録音音声は含まれません。メロディ保管庫は「保管庫バックアップ」で別途書き出してください。

## 保存とプライバシー

アプリが保存する場所は、開いているブラウザとURL（オリジン）に紐づく**端末内ストレージ**です。別の端末や別のURLへ自動同期される仕組みではありません。Safariのサイトデータを消す、プライベートブラウズを使う、ストレージ制限やOSの自動消去が起きる場合、保存内容が失われる可能性があります。**作業ごとに「プロジェクト書出し」と「保管庫バックアップ」をファイルアプリへ保存してください。**

- 自動保存：楽曲（音符・設定・録音）は従来の `KotobaMusicV30`（IndexedDB）を引き継ぎます。メロディ保管庫は `KotobaStudioVaultV1` の別領域です。
- 過去データ：**同じURLでKotoba Music v3.8.0を置き換える場合**、ブラウザに残った作品データを復元する設計です。**別URLから移す場合**は、旧アプリでプロジェクト書き出し → 新アプリで「開く」を実行してください。
- 外部通信：アプリ本体の読み込み・更新確認にはGitHub Pagesへのアクセスが発生します。ユーザーの録音・楽曲データを外部サービスへ送信する機能は追加していません。
- 知的財産：本アプリはユーザーの制作音源を学習データとして収集しません。制作物の権利は本アプリへ移転しません。

## 今回実装した範囲と制約

✅ 既存の録音→旋律抽出、ピアノロール、部分録り直し、複数トラック、楽器音、WAVとプロジェクトJSON保存機能を土台として維持。新たにセクション管理、歌詞の保管、選択音符への歌詞付与、コード伴奏、保管庫（音声Blobと音符）、MIDIの読み込み・書き出し、インストール可能なPWAを追加。

⚠️ **引き続き未実装**：音符単位の歌声合成・歌詞の自動音節割当、録音波形をセクション移動に同期するオーディオ編集、参考曲の自動コード推定、プラグイン方式の音質処理、既存の他アプリ独自ファイル形式の直接読み込み。MIDIインポートは標準的な形式0/1で、途中のテンポ変更やSMPTE時間形式を完全には再現しません。

⚠️ この環境ではHTML/JS構文とデスクトップブラウザ上の主要画面操作を確認しました。**iPad実機でのマイク・ストレージの耐久試験は未完了**です。大切な録音は、テスト後も必ず書き出してバックアップしてください。
