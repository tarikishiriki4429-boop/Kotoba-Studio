# Kotoba Studio v4.5.0 — GitHub Pages / iPad用

## 更新手順
1. このZIPを解凍します。
2. GitHubリポジトリのトップ階層に `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` をアップロードして既存ファイルを置換し、Commitします。
3. GitHub Pagesの反映後、ブラウザを更新してください。古い画面のままならページを再読み込みします。SafariのWebサイトデータを削除するとブラウザ内の作品が失われるおそれがあります。
4. 変更前に「書き出し → プロジェクトをバックアップ」でJSONファイルを保存してください。

## v4.5.0
- 音符・録音を開くと「ピアノロール」の詳細編集を優先表示。上部に「譜面で確認」「ブロックを編集（十字キー）」「録音・音声取込」を設置。
- 「構成・作詞」に録音、外部音声ファイル取り込み、再解析、元声の試聴、折れ線グラフを追加。
- グラフは音程解析後の音符から計算した音程線で、元音声そのものの連続F0を表示するものではありません。薄い棒は元音声の音量の目安です。
- グラフ上の音符から、同一音符データを使うピアノロール詳細編集へ移動可能。譜面表示とも同期。
- ミックスをダイヤル方式に変更。上下ドラッグ、±ボタン、キーボード矢印で微調整できます。
- ミックス専用にパート別Web Audioライブ試聴を追加。再生中の音量・パン・EQ・コンプレッサー・リバーブ・ミュート・ソロ・音量オートメーションを反映。
- 全体再生用の互換方式と、ライブ試聴用Web Audioは音の生成方法が異なるため、試聴とWAV書き出しの音質・効果に差が出る場合があります。
- ライブ試聴は現段階で6分以内のプロジェクトが対象です。長い曲／大量トラックは端末のメモリ・処理性能によって時間がかかったり再生できない場合があります。

## 注意点
- iPadのSafariによる実機検証は未了です。Chromiumブラウザ上で基本操作、音声取り込みから音符・グラフ・譜面への反映、ライブ試聴中の操作を確認しました。
- 録音機能はマイクのアクセス許可が必要です。GitHub Pages等のHTTPSサイトでご利用ください。
- 外部音声ファイルの取り込みは既存のトラック録音と音符を更新する場合があります。変更前にバックアップを保存してください。
- サイトを開いた時のIndexedDB保存領域はブラウザ／端末／ドメインごとです。他端末への自動同期機能はありません。
- ネットワークなしの動作はサイトのキャッシュに依存します。プロジェクトはJSONとして定期的に外部保存してください。
